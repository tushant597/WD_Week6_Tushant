# TaskFlow – Task Management Website

TaskFlow is a responsive and interactive task management website built using HTML, CSS, and JavaScript.

The project was created as the final web development project for the internship and demonstrates concepts learned throughout the six-week program.

## Project Objective

The objective of TaskFlow is to provide a simple interface for creating, organizing, searching, filtering, and managing tasks.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* GitHub Pages
* Local Storage
* SVG

## Main Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Search tasks
* Filter tasks by status
* Filter tasks by category
* Filter tasks by priority
* Form validation
* Dynamic task statistics
* Local storage persistence
* Responsive design for desktop, tablet, and mobile

## JavaScript Concepts Demonstrated

The project uses:

* Variables
* Functions
* Arrays
* Objects
* Array methods
* DOM manipulation
* Event handling
* Conditional statements
* Form validation
* Local Storage

## Responsive Design

TaskFlow uses CSS Grid, Flexbox, and media queries to provide a responsive interface across different screen sizes.
