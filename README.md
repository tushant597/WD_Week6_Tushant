# TaskFlow – Task Management Website

TaskFlow is a responsive and interactive task management website developed as the final web development project of my internship.

The project demonstrates the practical use of HTML, CSS, JavaScript, Git, GitHub, and GitHub Pages.

## Project Objective

The objective of TaskFlow is to create a simple and responsive task management application that allows users to create, organize, search, filter, update, complete, and delete tasks.

## Project Overview

TaskFlow provides a dashboard where users can manage their daily tasks. Each task contains a title, description, category, priority, and due date.

The application dynamically updates task statistics and provides tools for searching and filtering tasks. Users can also edit existing tasks, delete tasks, and mark tasks as completed.

Task data is stored using browser Local Storage, allowing tasks to remain available even after refreshing the page.

The website is designed to work across desktop, tablet, and mobile devices.

## Challenges Faced

One of the main challenges was managing dynamically generated task cards using JavaScript. This was solved by storing task information as objects inside an array and using DOM manipulation to generate and update the interface.

Another challenge was implementing multiple filters and search functionality while ensuring that they worked together correctly.

Making the website responsive across different screen sizes was also challenging. CSS Grid, Flexbox, and media queries were used to solve these layout problems.
